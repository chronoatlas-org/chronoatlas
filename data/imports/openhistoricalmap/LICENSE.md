# License: OpenHistoricalMap

The files in this folder are derived from [OpenHistoricalMap](https://www.openhistoricalmap.org/),
whose data is dedicated to the public domain under
[CC0 1.0](https://www.openhistoricalmap.org/copyright). A few OpenHistoricalMap features carry
their own license tag. The import script skips any feature whose license tag isn't public domain,
and lists it in `manifest.json` for review.

OpenHistoricalMap asks, but doesn't require, to be credited as: "Map data courtesy of the
OpenHistoricalMap project, in the public domain unless otherwise noted." We show this in the
map's attribution and in [CREDITS.md](../../../CREDITS.md).
